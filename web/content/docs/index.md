# ELIZA API documentation

ELIZA is a deterministic fixture for testing AI SDK integrations: chat, streaming,
tool calls, speech, feature-hash embeddings, and procedural images. It makes no
upstream model calls. Responses test client behavior, not model intelligence.

**Hosted access is not live yet.** Use these examples against an existing ELIZA
instance. `example.com` is a placeholder, not an available endpoint.

- [First request](quickstart.md)
- [Provider routes and capabilities](providers.md)
- [Standalone SDK examples](sdks.md)
- [Authentication](authentication.md)
- [CI with GitHub Actions or Jenkins](ci.md)
- [Limits, retries, and fixture versions](limits.md)
- [Service status and publication](service.md)
- [Changelog](changelog.md)

The exported bundle includes `openapi.json`, runnable examples, and Markdown.
HTML documentation and sitemap publication follow with the Nuxt site. These
public docs/examples are MIT licensed independently of source-repository access.
