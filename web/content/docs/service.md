# Service status and publication

The hosted API, Nuxt site, accounts, and billing are not deployed yet. There is
no production domain, independent status URL, or uptime record to publish.
`example.com` in design examples is a placeholder.

Before public launch, this page must link to the actual status page, support
contact, terms, privacy policy, deployed limits, and supported fixture versions.
Those pages must identify the operator and reflect implemented retention,
processors, regions, cancellation, and incident procedures. Do not treat this
publication note as legal terms or a promise that an unavailable feature works.

The public documentation bundle contains only documentation, OpenAPI, and standalone
examples. Public-source access to the ELIZA implementation is not required to use
an available instance. Historical copies retain their existing license.
