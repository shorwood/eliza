# Program provenance

`1965/` is an unchanged copy of the MAD, FAP, and tape programs used by
[`rupertl/eliza-ctss`](https://github.com/rupertl/eliza-ctss) at revision
`62f115c5ed15384c365b7d93ab668174bceb5130`.

Those ELIZA and SLIP programs were transcribed from listings in Joseph
Weizenbaum's archive. Weizenbaum's estate released the archival code under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The three files under `1965/slip/reconstructed/` and their tests are
also CC0. See the upstream reconstruction card for the distinction between
archival and reconstructed material.

`1966/doctor.script` is Anthony Hay's corrected transcription of the script in
the January 1966 CACM appendix, copied from
[`anthay/ELIZA`](https://github.com/anthay/ELIZA) revision
`4ac38e6694526f2a5c849014d3312a20cdddf842`. Hay offers that work under CC0 or
MIT. Transcription comments are retained in the file and ignored only by the
record reader.

`1966/eliza.mad` is new reconstruction work in this repository. It is kept
separate so it cannot be mistaken for the 1965 program.
